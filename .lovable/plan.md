# إضافات HN Apps: مستخدمون + لوحة تحكم + مدونة + عدّاد زوار

كل ما هو موجود حالياً يبقى كما هو. هذه إضافات فقط.

## 0. إصلاح خطأين في البناء (أولاً)
حالياً البناء متوقف بخطأين نوعيين في `src/routes/apps.$appId.tsx` و `src/routes/categories.$catId.tsx` (استنتاج نوع بيانات الـ loader). سيتم إصلاحهما بقراءة المعرّف من `Route.useParams()` وجلب العنصر داخل المكوّن قبل أي عمل آخر.

## 1. تشغيل الباك-إند (Lovable Cloud)
الموقع حالياً يعمل ببيانات ثابتة في الكود بدون قاعدة بيانات. لتفعيل التسجيل ولوحة التحكم والمدونة والعدّاد نحتاج تشغيل Lovable Cloud (قاعدة بيانات + مستخدمون + تخزين، بدون أي حساب خارجي).

الجداول:
- `profiles` — بيانات المستخدم (الاسم، الصورة)
- `user_roles` — الأدوار (`admin` / `user`) في جدول منفصل لأسباب أمنية
- `apps` — التطبيقات (كل الحقول المطلوبة: package_name, category, description, icon, apk_url, version, size, android_version, downloads, rating, status)
- `categories` — التصنيفات
- `downloads` — سجل التحميلات
- `blog_posts` — مقالات المدونة (slug, title, excerpt, content, cover, published)
- `pages` — الصفحات القابلة للتحرير (الدعم، الخصوصية، الشروط…)
- `site_visits` + `site_stats` — عدّاد الزوار
- بيانات البداية: التطبيقات والتصنيفات الحالية (HN Chat, Market, Video, Car, DB, Cloud, Edu, Work) + 10 مقالات مدونة تُزرع مباشرة في قاعدة البيانات

## 2. نظام المستخدمين
- صفحة `/auth`: تسجيل الدخول + إنشاء حساب (بريد + كلمة سر)
- زر «تسجيل الدخول» في الشريط العلوي، ويتحول تلقائياً إلى قائمة الحساب (الملف الشخصي، تحميلاتي، لوحة التحكم للأدمن، تسجيل الخروج)
- زر «تسجيل الخروج» فعّال مع تنظيف الجلسة
- صفحة `/account`: بيانات المستخدم وسجل تحميلاته

## 3. لوحة التحكم (للأدمن فقط) على `/admin`
- نظرة عامة: عدد الزوار، التحميلات، المستخدمون، التطبيقات
- إدارة التطبيقات: إضافة/تعديل/حذف + رفع الأيقونة وملف APK
- إدارة التصنيفات
- إدارة المدونة: إنشاء/تحرير/نشر المقالات
- إدارة الصفحات: تحرير نصوص الصفحات (الدعم، الخصوصية، الشروط، عن الموقع)
- إدارة المستخدمين والأدوار
- محمية بفحص الدور على السيرفر (ليس فقط في الواجهة)

## 4. المدونة
- زر «المدونة» في الشريط العلوي والفوتر
- `/blog` قائمة المقالات، `/blog/$slug` صفحة المقال
- 10 مقالات جاهزة تشرح الموقع: ما هو HN Apps، كيف تحمّل تطبيقاً، تثبيت APK بأمان، شرح HN Chat / HN Market / HN Video / HN Car / HN DB، سياسة التحديثات، الأسئلة الشائعة
- كل مقال له عنوان ووصف ومعاينة اجتماعية خاصة به (SEO)

## 5. عدّاد الزوار
- يُحسب مرة لكل زائر في اليوم، ويُعرض في أسفل الصفحة الرئيسية: إجمالي الزيارات، زوار اليوم، المتصلون الآن (تقريبي)

## 6. الفوتر في كل الصفحات
- «جميع الحقوق محفوظة للحسني مولاي اسماعيل — مجموعة اشن»
- رابط النطاق الجديد: https://fondation.hn-ai.store
- روابط: المدونة، الدعم، الخصوصية، الشروط

## 7. اقتراحات إضافية (أنفّذها إن وافقت)
1. المفضلة/قائمة الرغبات لكل مستخدم
2. تقييمات وتعليقات على التطبيقات (تقييم حقيقي بدل رقم ثابت)
3. بحث فوري + فلترة وترتيب (الأكثر تحميلاً، الأحدث)
4. إشعارات تحديثات التطبيقات (زر الجرس يعمل فعلياً)
5. صفحة «طلب تطبيق» / تواصل تصل إلى لوحة التحكم
6. خريطة موقع sitemap.xml + robots.txt وبيانات JSON-LD لتحسين ظهور الموقع في جوجل
7. لوحة إحصائيات تفصيلية (تحميلات لكل تطبيق عبر الزمن)
8. دعم لغة إنجليزية بجانب العربية

## ملاحظات تقنية
- الأدوار في `user_roles` + دالة `has_role` security definer؛ RLS + GRANT على كل جدول جديد.
- القراءة العامة (التطبيقات، التصنيفات، المقالات المنشورة) عبر سياسات `anon` للقراءة فقط.
- الكتابة (لوحة التحكم) عبر server functions مع `requireSupabaseAuth` + فحص دور admin داخل الـ handler.
- المسارات المحمية تحت `_authenticated/` مع بوابة التوجيه إلى `/auth`.
- رفع APK والأيقونات إلى تخزين Cloud بسياسات: قراءة عامة، كتابة للأدمن فقط.
- عدّاد الزوار عبر server function تُستدعى من الصفحة الرئيسية (بدون كشف أي بيانات شخصية).
- إضافة النطاق `fondation.hn-ai.store` كرابط؛ ربطه فعلياً كدومين للموقع يتم من إعدادات النشر.
